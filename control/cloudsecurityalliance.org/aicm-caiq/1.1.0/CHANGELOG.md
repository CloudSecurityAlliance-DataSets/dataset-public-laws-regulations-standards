# AI-CAIQ 1.1.0 — question changelog

Every question in AI-CAIQ 1.1.0, with what it was in 1.0.2 and
what changed. Derived by comparing the two extractions directly and generated by
[`../../aicm/crosswalks/build_caiq_changelog.py`](../../aicm/crosswalks/build_caiq_changelog.py).

Questions are matched **through their parent controls** rather than by text alone.
Question IDs derive from AICM control IDs, and the
[control crosswalk](../../aicm/crosswalks/aicm-1.0.3-to-1.1.0-crosswalk.csv)
is independently verified, so it is stronger evidence than question text — which is
short, heavily templated, and reworded routinely without changing meaning.

## The short version

- **183 of 320 questions are unchanged** in every respect.
- **70 questions were renumbered** — same question, different ID.
- **48 questions were materially reworded**; another 22
  were cosmetically edited.
- **11 questions are new**; **2 were removed**.
- **63 question IDs now ask a different question** than they did in
  1.0.2.

> ### A completed 1.0.2 questionnaire cannot be re-scored against 1.1.0
>
> 63 question IDs carried over attached to a different question.
> Matching a vendor's stored answers to this release by question ID will silently
> attach responses to questions they never answered.
>
> This follows from the AICM control renumbering — see
> [`../../aicm/VERSIONING.md`](../../aicm/VERSIONING.md). Migrate through the
> [question crosswalk](../../aicm/crosswalks/aicm-caiq-1.0.2-to-1.1.0-crosswalk.csv),
> never by string match.

## How to read the table

| Value | Meaning |
|---|---|
| `Unchanged` | Same ID, identical question text |
| `Renumbered` | Same question, different ID |
| `Reworded` | Question text materially changed (below 0.95 similarity) |
| `Edited` | Whitespace or trivial wording change only |
| `New` | No predecessor in the previous release |

**Notes** carries the ID-reuse warning — what happened to the *identifier*, which is
independent of what happened to the question — plus any parent-control renumbering.

## Machine-readable form

Use [`aicm-caiq-1.1.0-changelog.json`](aicm-caiq-1.1.0-changelog.json)
rather than parsing this table. Each entry in `questions` carries `question_id`,
`control_id`, `question`, `previous_question_id`, `previous_control_id`, `changes[]`,
`text_similarity`, `status`, `match_how`, and `id_reuse`.

```python
import json
changelog = json.load(open("aicm-caiq-1.1.0-changelog.json"))
repointed = [q for q in changelog["questions"] if q["id_reuse"]]
```
