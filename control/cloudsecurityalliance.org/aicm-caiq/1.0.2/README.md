# AI-CAIQ v1.0.2

`secid:control/cloudsecurityalliance.org/aicm-caiq@1.0.2`

The vendor self-assessment questionnaire companion to
[AICM v1.0.3](../../aicm/1.0.3/).

**Superseded by [AI-CAIQ v1.1.0](../1.1.0/) (released 2026-06-22).** The
questionnaire jumped 1.0.2 → 1.1.0 to version in lockstep with AICM; there is no
AI-CAIQ 1.0.3.

> ## ⚠️ Question IDs changed meaning in v1.1.0
>
> **These question IDs are not interchangeable with v1.1.0 question IDs.**
>
> Question IDs derive from AICM control IDs (`LOG-15.1` belongs to control
> `LOG-15`), and AICM v1.1.0 renumbered controls in place. **The question IDs
> moved with them.** `LOG-15.1` asks about Output Monitoring here and Input
> Monitoring in v1.1.0.
>
> **63 of the 302 question IDs this version shares with v1.1.0 ask a different
> question there.** A questionnaire completed against this version cannot be
> re-scored against v1.1.0 by matching question IDs.
>
> Per-question detail: [`../1.1.0/CHANGELOG.md`](../1.1.0/CHANGELOG.md). Migrate
> through the
> [question crosswalk](../../aicm/crosswalks/aicm-caiq-1.0.2-to-1.1.0-crosswalk.csv).
>
> Anything you cite from this directory must say "AI-CAIQ 1.0.2" explicitly.
>
> Full analysis: [`../../aicm/VERSIONING.md`](../../aicm/VERSIONING.md)
