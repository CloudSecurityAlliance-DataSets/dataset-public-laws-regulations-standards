# AICM 1.1.0 — control changelog

Every control in AICM 1.1.0, with what it was in 1.0.3 and what
changed. Derived by comparing the two extractions directly — identifiers, titles,
and specification text — and generated by
[`../crosswalks/build_changelog.py`](../crosswalks/build_changelog.py).

## The short version

- **127 of 247 controls are unchanged** in every respect.
- **53 controls were renumbered** — same requirement, different identifier.
- **34 specifications were materially rewritten**; another
  35 were cosmetically edited.
- **6 controls are new**; **2 were removed**.
- **54 identifiers now designate a different control than they did**
  in 1.0.3.

> ### Read this before reusing any 1.0.3 control ID
>
> The renumbering was done in place. 54 identifiers survived into
> 1.1.0 attached to a different control, while only
> 1 identifier from 1.0.3 is absent altogether.
> Comparing the two releases by their lists of control IDs therefore shows almost
> nothing wrong.
>
> A stored reference to `LOG-15` still resolves in 1.1.0. It just answers
> with a different requirement than it used to. Rows where this applies are marked
> **⚠ ID reuse** below.
>
> Cite AICM control IDs with a version — `AICM 1.1.0 LOG-15`, never
> `AICM LOG-15` — and migrate stored references through
> [`../crosswalks/aicm-1.0.3-to-1.1.0-crosswalk.csv`](../crosswalks/aicm-1.0.3-to-1.1.0-crosswalk.csv),
> never by string match.

## How to read the table

**Was in 1.0.3** names the identifier the same control carried in the previous
release, with its old title where that also changed. A dash means the control is new.

| Value in *What changed* | Meaning |
|---|---|
| `Unchanged` | Same identifier, same title, identical requirement text |
| `Renumbered` | Same control, different identifier |
| `Retitled` | Same control, different title |
| `Rewritten` | Requirement text materially changed (below 0.95 similarity) |
| `Edited` | Whitespace, typo, or boilerplate-clause change only |
| `New` | No predecessor in the previous release |

Several values can apply at once — a control may be renumbered *and* retitled *and*
rewritten. The **Notes** column carries the ID-reuse warning, which is independent of
everything else: it describes what happened to the *identifier*, not to the control.
