# GOV.UK One Login — UK Digital Identity Service

## Overview

UK government's emerging single digital-identity service replacing GOV.UK Verify. Operates alongside the UK Digital Identity and Attributes Trust Framework (DIATF).

Companion: UK DIATF — the trust framework for certifying private-sector identity and attribute providers operating in the UK.

## License and access

Public technical docs at docs.sign-in.service.gov.uk; participant onboarding partly restricted.
