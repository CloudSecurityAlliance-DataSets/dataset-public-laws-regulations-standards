# Kantara Identity Assurance Framework

## Overview

Kantara IAF — the core trust framework Kantara uses to certify identity providers against NIST SP 800-63 levels and ISO/IEC 29115.

Kantara also publishes the Consent Receipt Specification (free) for machine-readable consent records under GDPR/PIPEDA.

## License and access

Mixed access — some IAF specs are free, some assurance materials are members-only.
