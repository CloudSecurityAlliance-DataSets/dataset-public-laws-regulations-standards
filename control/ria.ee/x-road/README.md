# X-Road — Estonian Secure Data-Exchange Platform

## Overview

Estonia's secure data-exchange platform, the technical backbone of e-Estonia. Adopted by 20+ countries as their digital-government interoperability layer.

X-Road is the canonical reference for nation-state digital infrastructure. Estonia + Finland co-maintain via the Nordic Institute for Interoperability Solutions (NIIS).

## License and access

Open-source platform with free specifications. Estonian operational/security guidance partly restricted.
