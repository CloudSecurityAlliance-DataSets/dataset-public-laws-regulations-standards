# SEPA Credit Transfer (SCT) Rulebook

## Overview

The EPC SCT Rulebook governs euro credit transfers across the Single Euro Payments Area (SEPA). It's the operating rulebook for one of the world's largest payment schemes by transaction volume, covering 36 SEPA countries. Companion schemes:

- **SCT Inst** — real-time credit transfer (10-second settlement)
- **SDD Core** — SEPA Direct Debit for consumers
- **SDD B2B** — SEPA Direct Debit for businesses

Security and risk-management requirements include strong-customer-authentication alignment with PSD2, anti-fraud measures, and ISO 20022 message-security profiles.

## License and access

Public rulebook download; participation requires EPC member-bank status. Some operational specs are members-only.
