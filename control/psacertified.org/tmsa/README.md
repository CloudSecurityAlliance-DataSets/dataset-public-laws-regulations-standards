# PSA Threat Model and Security Analysis (TMSA)

## Overview

Reference Threat Model and Security Analysis for IoT devices. Foundational document for the PSA Certified Level 1/2/3 evaluation scheme.

Companion PSA Certified materials: Level 1 (self-assessment), Level 2 (lab evaluation, formal claims of security), Level 3 (lab evaluation with substantial security claims). Aligned with NIST IR 8259, ETSI EN 303 645.
