# CIS Controls 8

The CIS Critical Security Controls v8 is a prioritized set of 18 Controls (153 Safeguards) for defending against pervasive cyber attacks.

- **Name:** CIS Critical Security Controls
- **Owner:** Center for Internet Security (CIS)
- **SecID:** `secid:control/cisecurity.org/cis-controls@8`
- **Source:** https://www.cisecurity.org/controls/v8/
- **Licence:** `CC-BY-NC-ND-4.0`, publicly redistributable: no
