# ETSI ISG QSC — Quantum-Safe Cryptography

## Overview

ETSI ISG QSC deliverables — covering post-quantum cryptography migration, hybrid key exchange, and quantum-safe TLS/IPsec profiles.

Notable deliverables: TS 103 744 (Quantum-safe Hybrid Key Exchanges), TR 103 619 (PQC migration strategies). Complements NIST PQC (algorithm standardization stream — also free).
