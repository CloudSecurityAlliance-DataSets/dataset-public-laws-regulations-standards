# ETSI EN 303 645 — Cyber Security for Consumer IoT

## Overview

ETSI EN 303 645 establishes baseline cybersecurity requirements for consumer IoT devices. It's the most widely-influential consumer-IoT cyber standard internationally, cited by:

- **NIST IR 8425** (US consumer IoT cybersecurity criteria)
- **UK Code of Practice for Consumer IoT Security** (PSTI Act 2022 underpinning)
- Singapore CLS (Cybersecurity Labelling Scheme)
- Various other national IoT-cyber regimes
