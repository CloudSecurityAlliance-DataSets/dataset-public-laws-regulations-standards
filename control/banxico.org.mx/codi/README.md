# CoDi — Mexican QR Real-Time Payments

## Overview

Cobro Digital — Mexican QR-code-based real-time payment system. Operates on top of SPEI (Mexican RTGS).

Companion: SPEI (Sistema de Pagos Electrónicos Interbancarios) — the underlying Mexican interbank real-time payment rail.
