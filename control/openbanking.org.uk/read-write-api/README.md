# UK Open Banking Read/Write API Specification

## Overview

UK Open Banking Read/Write API Specification — the technical and security specifications for the UK Open Banking ecosystem. Security profile based on FAPI 1.0 Advanced.

Mandated for the CMA9 UK retail banks; widely adopted globally as a reference implementation. Companion private-repo entries for Berlin Group NextGenPSD2, STET, PolishAPI.

## License and access

Specifications mostly free; some certification materials paid/restricted.
