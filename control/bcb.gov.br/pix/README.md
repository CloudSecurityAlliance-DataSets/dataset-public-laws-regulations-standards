# PIX — Brazilian Real-Time Payments System

## Overview

World's 2nd-largest RTP by volume (after India's UPI). Launched 2020; processes billions of transactions monthly.

PIX uses QR-codes, aliases (CPF/CNPJ/email/phone), and instant settlement. Reference design exported to other Latin American countries.
