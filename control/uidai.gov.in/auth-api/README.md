# Aadhaar Authentication API Specification

## Overview

World's largest biometric digital-identity authentication API. Technical specification for biometric and demographic authentication against Aadhaar, used by all AUAs (Authentication User Agencies) and KUAs (KYC User Agencies). Aadhaar has 1.3B+ enrolled identities.

AUA/KUA participation contracts (which embed additional information security audit requirements) are members-only / NDA-restricted. Companion stubs at digilocker, npci for India Stack coverage.
