# PCI DSS 4.0

PCI DSS v4.0 (March 2022) was a major revision from v3.2.1, introducing the Customized Approach as an alternative to the Defined Approach, plus expanded targeted risk analysis and continuous evolution requirements.

- **Name:** Payment Card Industry Data Security Standard
- **Owner:** PCI Security Standards Council, LLC
- **SecID:** `secid:control/pcisecuritystandards.org/pci-dss@4.0`
- **Source:** https://www.pcisecuritystandards.org/document_library/
- **Licence:** `LicenseRef-PCI-SSC-Read-Copy-License`, publicly redistributable: no
