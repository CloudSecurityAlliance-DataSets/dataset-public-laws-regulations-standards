# UPI — Unified Payments Interface

## Overview

UPI is the world's largest real-time payments system by volume (10B+ transactions monthly as of 2024). Account-to-account instant transfers using virtual payment addresses (VPAs); core to India Stack.

NPCI also runs RuPay (domestic card scheme) and IMPS (legacy instant payments). UPI dominates Indian retail payments — heavily exported as a model to other countries (PIX in Brazil, FedNow in US are conceptual cousins).

## License and access

Technical API specs partly public; participant security rules and operational guidelines members-only via NPCI participation agreements.
