# PromptPay — Thai Real-Time Payments

## Overview

Thai real-time payment system using national-ID or mobile-number as payee identifier. Operated by BoT.

Cross-border PromptPay-PayNow link with Singapore (since 2021); first such RTP-to-RTP linkage globally.

## License and access

Operational rules published by BoT; participant security partly members-only.
