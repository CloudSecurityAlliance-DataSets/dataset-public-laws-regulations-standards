# CWE-449: The UI Performs the Wrong Action

## Description

The UI performs the wrong action with respect to the user's request.

| --- | --- |
| [CVE-2001-1387](https://www.cve.org/CVERecord?id=CVE-2001-1387) | Network firewall accidentally implements one command line option as if it were another, possibly leading to behavioral infoleak. |
| [CVE-2001-0081](https://www.cve.org/CVERecord?id=CVE-2001-0081) | Command line option correctly suppresses a user prompt but does not properly disable a feature, although when the product prompts the user, the feature is properly disabled. |
