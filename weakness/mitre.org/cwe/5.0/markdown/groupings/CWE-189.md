# CWE-189: Numeric Errors

## Summary

Weaknesses in this category are related to improper calculation or conversion of numbers.

## Mapping Notes

- **Usage:** Prohibited
- **Rationale:** This entry is a Grouping. Using groupings for mapping has been discouraged since 2019. They are informal organizational groupings of weaknesses that can help CWE users with data aggregation, navigation, and browsing. However, they are not weaknesses in themselves [REF-1287]. This CWE ID may have become widely-used because of NIST's usage in NVD from 2008 to 2016 (see CWE-635 view, updated to the CWE-1003 view in 2016).
