## Notes

- **Maintenance** (CWE 5.0, 2026-10-27): This CWE entry has been deprecated. For many years, the intention and usage of this CWE entry has evolved to include many notions of "sessions" that are not specific to the web. Instead of expanding the scope of this entry, it was split into multiple separate entries. The original WASC-47 entry [REF-1520] includes considerations forcing re-authentication for "inactivity" (expiring sessions after a period of inactivity) versus "absolute" (a fixed expiration time), with a goal to "keep the lifespan of a session ID as short as possible." However, this CWE was also used for situations in which a session is not fully invalidated or terminated upon logout, which is a different weakness than the original intention for this entry. There is also evidence that this CWE entry was used for session fixation (CWE-384).
