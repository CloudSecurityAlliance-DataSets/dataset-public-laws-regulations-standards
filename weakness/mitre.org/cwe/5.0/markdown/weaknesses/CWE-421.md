# CWE-421: Race Condition During Access to Alternate Channel

## Description

The product opens an alternate channel to communicate with an authorized user, but the channel is accessible to other actors.

| --- | --- |
| [CVE-1999-0351](https://www.cve.org/CVERecord?id=CVE-1999-0351) | FTP "Pizza Thief" vulnerability. Attacker can connect to a port that was intended for use by another client. |
| [CVE-2003-0230](https://www.cve.org/CVERecord?id=CVE-2003-0230) | Product creates Windows named pipe during authentication that another attacker can hijack by connecting to it. |
