# CWE-1008: Architectural Concepts

**View type:** Graph · **Status:** Obsolete

> **Obsolete.** MITRE marks this view as obsolete: kept for reference, no longer maintained.
>
> Only the objective, status and content history of an obsolete or deprecated view are rendered here. Not rendered from MITRE's XML for this view: audience, members, references, mapping notes and notes. MITRE's page: <https://cwe.mitre.org/data/definitions/1008.html>

## Objective

This view organizes weaknesses according to common architectural security tactics, as proposed in 2017 as part of an academic "Common Architectural Weakness Enumeration (CAWE)" project. The view was intended to assist architects in identifying potential mistakes that can be made when designing software.
