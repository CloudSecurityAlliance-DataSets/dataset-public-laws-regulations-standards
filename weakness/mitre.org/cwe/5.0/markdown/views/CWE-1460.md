# CWE-1460: Weaknesses Addressed by the Top 20 Secure PLC Coding Practices

**View type:** Explicit · **Status:** Stable · **Members:** 13 weaknesses

## Objective

CWE entries in this view (graph) are fully or partially eliminated by following the guidance presented in the Top 20 Secure PLC Coding Practices, as published by the Secure PLC Programming project in 2021.

## Audience

- **Software Developers**: By following the practices in the list, PLC developers will be able to fully or partially prevent the weaknesses that are identified in this view. In addition, developers can use a CWE coverage graph to determine which weaknesses are not directly addressed by the guide, which will help identify and resolve remaining gaps in training, tool acquisition, or other approaches for reducing weaknesses.
- **Product Customers**: If a developer claims to be following these practices, then customers can search for the weaknesses in this view in order to formulate independent evidence of that claim.
- **Educators**: Educators can use this view in multiple ways. For example, if there is a focus on teaching weaknesses, the educator could link them to these practices.
