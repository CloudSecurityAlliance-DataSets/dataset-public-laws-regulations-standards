# CWE-462: Duplicate Key in Associative List (Alist)

## Description

Duplicate keys in associative lists can lead to non-unique keys being mistaken for an error.

## Background Details

For some kinds of association lists, a duplicate key entry is a valid operation that replaces the original key in constant time.

## Modes Of Introduction

- **Implementation**: Duplicate key entries could be inserted by mistake, introducing an ambiguity.

## Likelihood Of Exploit

Low

## Common Consequences

| Scope | Impact | Note |
| --- | --- | --- |
| Other | Quality Degradation<br>Varies by Context | If an alist contains duplicate key entries, this introduces an ambiguity in which it cannot be predicted which key value will be selected. |

## Detection Methods

- **Method:** Automated Static Analysis · **ID:** DM-14

  Automated static analysis, commonly referred to as Static Application Security Testing (SAST), can find some instances of this weakness by analyzing source code (or binary/compiled code) without having to execute it. Typically, this is done by building a model of data flow and control flow, then searching for potentially-vulnerable patterns that connect "sources" (origins of input) with "sinks" (destinations where the data interacts with external components, a lower layer such as the OS, etc.)

## Potential Mitigations

- **Phase:** Implementation

  Use a hash table instead of an alist.

- **Phase:** Implementation

  Use an alist which checks the uniqueness of hash keys with each entry before inserting the entry.

- **Phase:** Implementation

  Duplicate key entries in an association list are not recommended and should not be allowed.

## Demonstrative Examples

### Example 1

The following code adds data to a list and then attempts to sort the data.

*Example (Bad, Python):*

```python
alist = []
while (foo()): #now assume there is a string data with a key basename
    queue.append(basename,data)
    queue.sort()
```

Since basename is not necessarily unique, this may not sort how one would like it to be.
