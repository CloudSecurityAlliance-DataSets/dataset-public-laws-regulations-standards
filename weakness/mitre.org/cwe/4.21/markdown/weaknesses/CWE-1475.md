# CWE-1475: Incomplete Data/State Propagation

## Description

The product passes control to another component or function, or it performs a state transition, but it does not provide some security-critical data/state that is needed by the receiving component/function.

## Common Consequences

| Scope | Impact | Note |
| --- | --- | --- |
| Other | Unexpected State<br>Varies by Context | The consequences will vary depending on the type of data/state that is omitted, along with the functionality that the data/state supports. |
| Access Control | Gain Privileges or Assume Identity<br>Bypass Protection Mechanism | If the data/state is needed for a security decision, such as authentication or authorization, then this could allow attackers to bypass the intended protection mechanism. |

## Potential Mitigations

- **Phase:** Implementation

  Clearly identify security-critical data/state structures and ensure that they are propagated when necessary. Be careful of error conditions that could redirect control flow in a way that prevents the propagation from occurring.
