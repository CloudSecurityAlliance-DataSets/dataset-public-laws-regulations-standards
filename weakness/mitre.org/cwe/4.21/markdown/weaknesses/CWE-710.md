# CWE-710: Improper Adherence to Coding Standards

## Description

The product does not follow certain coding rules for development.

## Weakness Ordinalities

- **Primary**
- **Indirect**

## Applicable Platforms

| Type | Class | Prevalence |
| --- | --- | --- |
| Language | Not Language-Specific | Undetermined |
| Technology | Not Technology-Specific | Undetermined |

## Common Consequences

| Scope | Impact | Note |
| --- | --- | --- |
| Other | Varies by Context | This can lead to resultant weaknesses or increase the severity of the associated vulnerabilities. |

## Detection Methods

- **Method:** Automated Static Analysis

  Automated tools can detect violations of many code standards.

## Potential Mitigations

- **Phase:** Policy

  Select and require coding standards. Ensure that they include security concerns.

- **Phase:** Implementation

  Closely follow coding standards, possibly enforcing them upon checkin of the code into a source control system or with periodic analyses.
