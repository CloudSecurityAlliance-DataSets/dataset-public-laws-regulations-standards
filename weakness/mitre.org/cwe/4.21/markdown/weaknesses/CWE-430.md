# CWE-430: Deployment of Wrong Handler

## Description

The wrong "handler" is assigned to process an object or request.

## Modes Of Introduction

- **Implementation**: This can happen when the product automatically "determines" the type of the object even if it is contradictory to an explicitly specified type.

## Common Consequences

| Scope | Impact | Note |
| --- | --- | --- |

## Potential Mitigations

- **Phase:** Architecture and Design

  Perform a type check before interpreting an object.

- **Phase:** Architecture and Design

  Reject any inconsistent types, such as a file with a .GIF extension that appears to consist of PHP code.
