# CWE-622: Improper Validation of Function Hook Arguments

## Description

The product adds hooks to user-accessible API functions, but it does not properly validate the arguments.

## Modes Of Introduction

- **Implementation**: Function hooks can be used in defensive software that runs with privileges, such as anti-virus or firewall, which hooks kernel calls.

## Common Consequences

| Scope | Impact | Note |
| --- | --- | --- |
| Integrity | Unexpected State<br>Bypass Protection Mechanism | When the arguments are not validated, they could be used to bypass the protection mechanism or attack the product itself. This could lead to resultant vulnerabilities. |

## Potential Mitigations

- **Phase:** Architecture and Design

  Ensure that all arguments are verified, as defined by the API you are protecting.

- **Phase:** Architecture and Design

  Drop privileges before invoking such functions, if possible.
