# CWE-1468: Weaknesses Addressed by the OWASP Golang Secure Coding Practices Guide

**View type:** Explicit · **Status:** Incomplete · **Members:** 27 weaknesses

## Objective

CWE entries in this view (slice) are fully or partially eliminated by following the guidance presented in the OWASP Golang Secure Coding Practices Guide.

## Audience

- **Software Developers**: By following this coding guide, Go developers will be able to fully or partially prevent the weaknesses that are identified in this view. In addition, developers can use a CWE coverage graph to determine which weaknesses are not directly addressed by the guide, which will help identify and resolve remaining gaps in training, tool acquisition, or other approaches for reducing weaknesses.
- **Product Customers**: If a software developer claims to be following this coding guide, then customers can search for the weaknesses in this view in order to formulate independent evidence of that claim.
- **Educators**: Educators can use this view in multiple ways. For example, if there is a focus on teaching weaknesses, the educator could link them to this relevant Secure Coding Guide.
